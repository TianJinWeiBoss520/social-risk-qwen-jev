# 数据卡

## 来源与任务

- 来源：[LT-EDI中文厌女表情包仓库](https://github.com/AJFaisal002/Mysogyny-Meme-Detection)。
- 固定来源commit：`0179687f197a0b2babddcb4eb32547a07cba0933`。
- 原始数据：1190 train、170 dev；每条包括图像、转录和二值 `Misogyny / Not-Misogyny`。
- 任务：中文图文厌女/针对女性的冒犯识别，不是通用诈骗、涉政、色情或辱骂风控。
- 原始共享任务说明：[ACL官方概述](https://aclanthology.org/2025.ltedi-1.32/)。

## 质量检查

下载阶段核对来源字节；随后检查Pillow可读性、SHA256字节/像素重复、dHash近重复及文本组件。排除1条多帧样本和39条去重/跨划分保护记录，原文件未删除。组交集为0，只针对这些启发式检查；dHash近似并不证明语义重复。

来源ID `train:...` 指原始来源；即使ID以train开头也可能属于本项目验证集，训练时必须依据manifest而不是ID前缀。

## 标签与政策限制

原数据只有二值标签，没有解释真实性、严重度或概率标注。通用辱骂、反歧视引用、反讽与性别攻击容易出现口径争议。保留源标签，另记诊断，不为了模型成绩重标旧测试。

用户只做过政治内容抽查，状态为 `USER_SPOT_CHECK_ONLY; NOT_FULLY_VERIFIED`，不能保证数据中不存在任何政治敏感内容。

## 发布与许可

本仓库不再分发原图、转录、逐条标签或私人诊断。第三方仓库可访问不等于取得任意再分发权；下载、研究和再分发前自行确认原始数据提供方条款。项目代码许可证不覆盖数据、模型权重或外部API。
