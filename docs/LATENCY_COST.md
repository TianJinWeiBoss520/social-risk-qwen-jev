# 速度、调用量与成本

以下来自历史报告，不是本次重新压测。CPU、GPU、API 的计时范围不同，不能按“快多少倍”直接作同口径比较。单请求时延也不等于并发吞吐/QPS。

## 传统方法：测试集 batch=1

计时仅含已加载 TF-IDF 的 transform 与已加载分类器的预测，不含进程启动、文件读取、模型加载、服务排队和网络。按均值由快到慢：

| 方法 | 均值 | P50 | P95 |
|---|---:|---:|---:|
| TF-IDF + LR C=1 | 0.297 ms | 0.292 ms | 0.325 ms |
| TF-IDF + LR C=4 | 0.298 ms | 0.295 ms | 0.329 ms |
| TF-IDF + XGBoost depth=2 | 0.519 ms | 0.511 ms | 0.561 ms |
| TF-IDF + XGBoost depth=4 | 0.537 ms | 0.527 ms | 0.613 ms |

微秒级差异受运行环境影响，不应据此断言 C=1 在生产环境必然更快。TF-IDF 本身只读取转录文本，不是图文模型。

## GPU / 云端组件：验证阶段

| 已观察组件 | 样本 / 请求范围 | 均值 | P50 | P95 |
|---|---|---:|---:|---:|
| 纯 Jev 文本 | 172 记录，171 唯一新增 POST | 1.231 s | 0.956 s | 2.382 s |
| 多模态 Jev 决策组件 | 172 记录的历史调用 | 1.171 s | 0.905 s | 2.272 s |
| Qwen LoRA 七字段证据 | 172 图文记录，本地模型已加载 | 5.182 s | 5.113 s | 6.229 s |

两个 Jev 实验调用时间不同；0.06s 均值差不能当成服务端模型更快的结论。Jev 只做文本/结构化决策，不包含上游 GPU 读取图像和证据生成成本。

历史逐条时延相加重建的验证链路均值约 6.353s、P50 6.207s、P95 7.641s。**这是缓存重建，不是实际线上端到端服务压测。** 不能把两个组件 P95 直接相加叫整体 P95。

## 最终测试：重建的链路与级联

- Qwen LoRA 证据均值 5.210s；Jev 往返均值 1.338s；历史相加约 6.548s/条。
- “文本先报阳性即可复核，否则才走大模型”模拟中，170 条有 35 条可跳过昂贵链路，跳过比例 20.59%，重建均值约 5.097s。
- 级联数字使用既有缓存模拟，不是实际部署测量。跳过样本没有 Jev 分数，不能凭空填为 0 或伪造低/中/高风险分段。
- OR 规则的两路分类语义可以级联实现，但延迟、覆盖率、隐私发送量与概率展示需重新做真实服务测试。

潜在工程优化：缓存图文感知、同图复用处理、短输出/批推理、异步 API、仅不确定样本走高成本模型。这里没有实现并压测上述优化，不展示臆造加速比。

## API 费用：已知成功请求的 token 估算

| 历史批次 | 新增调用范围 | 估算美元 |
|---|---|---:|
| 验证图文 Jev | 先20条、再152条，复用前20 | 0.005214804 |
| 冻结测试 Jev | 170条 | 0.005135424 |
| 纯文本 Jev 开发消融 | 171唯一请求覆盖172条 | 0.004303362 |
| 纯文本 Jev 补充测试 | 104成功＋66续跑；另1次超时计费未知 | 约0.00425519 |
| 合计 | 上述已知成功请求批次 | 约0.01890878 |

采用实验报告的 token 与单价计算；它**不是完整账户账单**，不含 GPU 租费、税、其他使用、未知失败请求或额外服务费用。真实价格须在调用前核对 [TypeSafe 官方模型文档](https://docs.typesafe.ai/models)。本次项目归档 API 调用数为零。

原 runner 用保守 reserved estimate、最大唯一 POST 数、持久化账本、零自动重试和预算预检控制软件行为。0.50美元的软件预测上限、用户授权5美元额度都不是服务商硬账单上限；超时不自动重发。不要声称“绝不会有高额账单”。

纯 Jev 补充测试只在用户明确授权后重发原不确定的第105次请求，新增请求最多66次，不重复成功的104条；累计171次尝试、170条有效分数。一次原超时可能已经计费，未包含在成功请求合计中。原104条输入费用估算0.002606352美元，续跑日志新增约0.00164884美元；日志未提供本次时延分布，不新增测试速度榜数据。详见 [补充测试记录](PURE_JEV_TEST_SUPPLEMENT.md)。
